# Güvenlik / Security

1.x sürümü desteklenir. Güvenlik açığı için deponun Security → Advisories → Report a vulnerability
özelliğini kullanın; kullanılamıyorsa bakımcıya özel bildirim kanalı soran, ayrıntı içermeyen issue açın.
Tokenı veya sömürülebilir ayrıntıları herkese açık paylaşmayın.
Sızan bot tokenını hemen Discord Developer Portal üzerinden resetleyin, yerel ayarı yenileyip botu yeniden başlatın.

Version 1.x is supported. Prefer GitHub private vulnerability reporting from Security → Advisories.
If unavailable, open an issue requesting a private contact channel without exploit details.
Never publish tokens, private data or exploit instructions. Reset exposed tokens in Developer Portal
immediately, reconfigure locally and restart.

No response-time guarantee is offered. Keep Node and locked dependencies patched.
This bot is a calculation aid, not a WCAG certification service. Ephemeral responses are not encrypted storage.
Operators must secure credentials, host access, backups and OS logs/dumps. See README for retention and limits.
